To get the macro's working, in OpenOffice or LibreOffice...
Open LibreOffice or OpenOffice Calc.
Goto, Tools - Options - Security (under LibreOffice or OpenOffice heading) - Click the Macro Security button - Change the Security Level to Medium.
Copy and Paste Macro's into:
Tools - Macro's - Edit Macros
into... LibreOffice Basic or OpenOffice Basic
